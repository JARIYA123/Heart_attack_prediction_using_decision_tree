# Heart_attack_prediction_using_decision_tree
# 📌 Project Overview

This project aims to predict heart attack risk using a Decision Tree Machine Learning algorithm.
It analyzes medical parameters such as age, heart rate, blood pressure, blood sugar, CK-MB, and Troponin levels to classify patients as positive or negative for heart attack risk.
# 📂 Dataset Information

Dataset name: Medicaldataset.csv ,
Target column: positive → Heart attack detected ,negative → No heart attack detected .
# 🔍 Features Used

Age ,Gender ,
Heart Rate ,
Blood Pressure ,
Blood Sugar ,
CK-MB ,
Troponin .
# 🛠️ Technologies Used

Python ,
Pandas ,
NumPy ,
Matplotlib ,
Seaborn ,
Scikit-learn ,
Jupyter Notebook .
# ⚙️ Machine Learning Algorithm

Decision Tree Classifier ,
Criterion: Gini Index ,
Max Depth: 5 .
# 🚀 Steps Followed

1. Load and explore the dataset
2. Encode target labels
3. Perform data visualization
4. Split data into training and testing sets
5. Train Decision Tree model
6. Evaluate using accuracy, confusion matrix, and classification report
# 📊 Model Performance

Accuracy: ~85–95% ,
Evaluation Metrics:
Accuracy Score ,
Confusion Matrix ,
Precision, Recall, F1-Score .
# 📌 Applications

Medical decision support systems ,
Healthcare analytics .
